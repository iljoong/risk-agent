# 입력, 추출, 근거

## 프리플라이트

모든 모드에서 자료명/형식/버전/추출 상태/주의사항을 원천 인벤토리로 기록한다.
총 페이지 수, 실제 처리한 고유 페이지 집합, OCR 여부, 누락 섹션을 추적한다.
최대 인용 페이지 번호는 전체 커버리지가 아니다. 읽은 페이지 범위를 합집합으로 계산한다.
HWPX XML 섹션 개수는 페이지 수와 다르므로 섹션 기준으로 명시한다.

- 텍스트가 매우 적거나 페이지당 평균 100자 미만이면 스캔 가능성 신호로 취급한다.
  짧은 정상 문서를 스캔으로 확정하지 말고 이미지/텍스트 상태를 확인한다.
- 대용량은 페이지/섹션 단위로 나눠 처리하고 근거 식별자를 유지하며 병합한다.
- PDF/DOCX는 호스트의 사용 가능한 추출 도구를 사용한다.
- 암호화/추출 실패는 변환본(DOCX/PDF/TXT/MD) 또는 원문 텍스트를 요청한다.
- HWP/HWPX 추출기는 텍스트/표를 추출하지만 페이지, 댓글, 변경 이력, 이미지 OCR을
  보장하지 않는다. 전략에 필요한 댓글/수정 이력은 별도 도구/사용자 자료로 확인한다.
- PrvText만 얻었거나 일부 원문을 사용할 수 없으면 전체 분석 완료로 표시하지 않는다.

## 커버리지 마크업

각 HTML에 한 개의 선언을 넣는다. 값은 실제 처리한 수량 또는 `unknown`이다.
단위는 `pages` 또는 `sections`; `partial`은 페이지 수 불명/누락/추출 실패 시 `yes`.
스캔 감지는 `yes`, `no`, `unknown` 중 하나다.

```html
<div id="source-coverage" data-unit="sections" data-covered="3"
     data-total="3" data-scanned="no" data-partial="no">
  원문 XML 섹션 3/3 처리 (페이지 커버리지 아님)
</div>
```

총량 불명, 부분 처리 또는 스캔/스캔 여부 불명이면
`class="coverage-warning"`인 **눈에 보이는** 경고를 넣는다.
추출 성공과 내용 검토 완료를 구분한다.

## 근거 레코드

중요한 날짜/금액/배점/자격/서류 요구마다 다음을 보존한다.

| 필드 | 의미 |
|---|---|
| 자료 | 실제 파일/공고명, 버전 |
| 위치 | 확인 가능한 페이지/조항/섹션; 모르면 검색 가능한 원문 구절 |
| 인용 | 원문 그대로, 필요한 최소 길이 |
| 값 | 추출값과 단위/VAT/타임존 |
| 유형 | 사실 / 분석 / 가정 / 확인 필요 |
| 신뢰도 | 상/중/하 + 이유; 검증되지 않은 확률 수치 금지 |
| 검토 상태 | 검토 완료 / 사용자 확인 필요 / 원문 미확인 |

공고/정정/RFP/첨부의 충돌은 양쪽 근거를 표시한다.
최신 정정임이 확인된 자료를 우선하되 우선순위가 불분명하면 확인 과제로 남긴다.
"원문 미명시"와 "명시적으로 요구하지 않음"은 다르다.
가정한 기한, 금액, 보증 비율, 예가 범위, 기관 URL을 원문 사실처럼 쓰지 않는다.
