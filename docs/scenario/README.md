# AI-assisted financial crime investigation scenario

This pack describes a fictional To Be operating model for a Financial Crime Investigator working alongside a Copilot Studio agent.

**Scope:** Scenario, inputs, outputs and process guide only. This is not a technical architecture, implemented application, or claim that controls have been deployed.

All organizations, people, records and policies are fictional. The global policy framework and local supplement illustrate an operating model, not legal requirements or proof of regulatory compliance.

## Journey

Transaction -> Suspicious Activity Detected -> AI Investigation -> Evidence Gathering -> Risk Analysis -> Human Review -> Decision -> Audit Record

Workbench chevrons:

Detect -> Investigate -> Gather Evidence -> Analyze -> Human Review -> Decision

Audit recording spans the entire journey. The agent assembles and maintains the investigation pack; the analyst challenges it, applies judgment and owns the defensible record. Consequential decisions remain with authorized humans in the existing approval workflow.
