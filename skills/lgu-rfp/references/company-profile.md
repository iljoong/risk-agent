# LG U+ 기업 전제와 참가자격

기존 업무 전제: LG U+는 대기업, LG 그룹 상호출자제한기업집단 소속이며
기간통신사업자, 정보통신공사업, 전기공사업, 부가통신사업자 등록을 보유한다.
이는 **제공된 기업 프로필**이지 현재 등록 상태를 확인한 결과가 아니다.
유효 증빙/사용자 확인을 확보하기 전 "증빙 확인 필요"를 표시한다.

| 원문 조건 | 분석 방향 |
|---|---|
| 대기업 참여제한, 중소기업자간 경쟁, 중소기업 확인서 | 직접 참여 제한 가능성; 예외/사업금액/공동수급 조건을 함께 확인 |
| 상호출자제한기업 참여제한 | 해당 제한과 예외의 원문 근거를 확인; 법무/발주처 확인 필요 |
| 면허/기간통신사업자 요구 | 기업 프로필상 보유, 유효 증빙과 정확한 업종/범위 확인 |
| 중소·소기업·창업기업 가점 | LG U+에는 해당 없음(대기업 전제); 구성원사 적용은 별도 확인 |
| 입찰보증금 | 공고의 면제/지급각서 조건 확인; 대기업이라는 이유만으로 자동 면제 금지 |
| 계약보증금 | 비율, 보증 방식, 지급각서 대체 허용 여부를 원문으로 확인 |

참여 가능성 박스에는 가능 / 조건부 / 불가 / 확인 필요, 원문 위치와 인용,
기업 전제의 확인 상태, 권장 조치를 포함한다.
키워드 발견만으로 제한을 확정하거나 컨소시엄이 제한을 우회한다고 단정하지 않는다.
색상은 가능=초록, 조건부/확인 필요=앰버, 불가=차콜로 사용한다.
법률 판단은 "경쟁 제한 가능성", "질의 권장", "법무 검토 필요"로 표현한다.
