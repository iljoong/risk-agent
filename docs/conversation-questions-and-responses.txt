I want to create a ChatGPT like app using Microsoft Agent Framework and GitHub Copilot SDK. 

## UX

- Provide similar UX, like chat history in left side bar and main chat window and can attach files and **call custom skills** in app from text input box.
- Use ChatGPT style and icons as possible but use your additional imagination if needed.
- Manage chat history.
- Support Markdown text rendering in chat window
- Show status progress and animated spinner icon while receiving response.
- Optional right sidebar show generated html contents by tasks

## Long/complex task and short/simple question handling
  
- Separate web and api, and handle long running process using HTTP async call for calling skills and other complex task. 
- Classify long running task and short question. In case of short question, app responses immediately with streaming. 
- Keep and manage generated contents in the chat session.
- Generated contents can be used as context for chat session. That is, user can ask a question regarding the generated content.

## Skill and tool support

- Custom skills are located in app's skill folder, auto-discover at startup time and developer will provide skills later.
- Generate a sample skill for the app
- Support custom tools just like skills. Tools are not callable only for the app.
